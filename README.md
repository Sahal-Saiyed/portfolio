# Muhammadsahal Saiyed — Portfolio

Personal portfolio for Muhammadsahal Saiyed, an AI/ML Engineer based in
Ahmedabad, India.

The site presents four detailed case studies:

- JuriGPT
- NEEV AI POC — freelance construction workflow agent
- CaptionCaptain
- RevCast AI

It also includes work experience, engineering capabilities, a downloadable
resume, direct social links, and an email contact form.
